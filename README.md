# IMPOSTORI

Party-game mobile-first në gjuhën shqipe. Loja përdor një telefon të vetëm, role private, timer, votim dhe databazë lokale me mbi 11,000 fjalë të vetme.

## Zhvillimi

```bash
npm install
npm run validate:words
npm test
npm run dev
```

## Funksionet

- 3–15 lojtarë dhe 1–5 impostorë me balancim automatik
- Mbi 11,000 fjalë të vetme, kategori të pasura dhe 3 nivele vështirësie
- Hint-e të drejtpërdrejta në nivelin e lehtë dhe më abstrakte në nivelin e vështirë
- WordEngine me historik lokal dhe Fisher–Yates shuffle
- Role private, timer, votim dhe rezultate
- Emra automatikë ose custom
- Statistika dhe cilësime në local storage
- PWA për instalim dhe lojë offline
